## 1. 产品定位

**一句话**：一个干净的跨界面悬浮计时工具——时钟、秒表、倒计时，悬浮在任意界面之上，拖到哪、看到哪。

- **目标用户**：考试控时的学生党、抢购对时的用户、烹饪/健身计时者、需要时刻看到时间进度的上班族
- **双端策略**：同一套产品与视觉语言，Android 与鸿蒙（HarmonyOS NEXT）各自原生开发；鸿蒙版额外吃到实况窗、服务卡片等系统能力
- **差异化**：无广告、权限克制、省电；鸿蒙端为该类目先发产品之一

## 2. 核心用户场景

| # | 场景 | 行为 | 悬浮窗需要 |
| --- | --- | --- | --- |
| S1 | 考试/刷题控时 | 开倒计时 60min，切到 PDF/网课 App | 倒计时悬浮在其它 App 上，每秒（或每分钟）刷新 |
| S2 | 秒杀抢购对时 | 开时钟+毫秒，卡点下单 | 毫秒级时钟悬浮，高对比样式 |
| S3 | 烹饪/运动正计时 | 开秒表，切到菜谱/健身视频 | 秒表悬浮、到点响铃（倒计时） |
| S4 | 停车计费提醒 | 开正计时记录停车时长 | 秒表 + 桌面小组件 |
| S5 | 随时看时间 | 全屏游戏/视频中抬头看时间 | 极简时钟悬浮，低透明度不遮挡 |

## 3. 功能范围（v1.0）

### 3.1 P0 —— MVP 必须

**F1 悬浮时钟（核心）**
- 显示当前时间 `HH:mm:ss`，可开启毫秒显示；毫秒位数可设 1–3 位（`.s` / `.ss` / `.sss`，**默认 1 位**，如 `HH:mm:ss.s`）；12/24 小时制切换；秒显示可关
- 可选显示：日期、星期、电量
- 悬浮窗交互：拖动移动、双击最小化（缩为小圆点）、贴边自动吸附、长按（或控制面板）调节
- 外观：大小 0.7×–3.8× **进度条式拖拽连续调节**（最大约占屏幕 1/4 面积，超大字号自动换行/自适应布局）、透明度（30%–100%）、6 种主题色、3 种背景样式（胶囊/方卡/纯文字描边）
- 记住位置与样式，下次启动恢复

**F2 秒表（正计时）**
- 启动 / 暂停 / 重置；悬浮窗内直接操作（点击展开控制条）
- 精度：秒级默认；毫秒显示位数可设 1–3 位（默认 1 位，P0 提供开关，默认关，省电）
- 计次：App 内计次列表（悬浮窗只显示当前值）

**F3 倒计时**
- 快捷时长：1/3/5/10/25/60 分钟 + 自定义（时:分:秒滚轮）
- 剩余时间悬浮显示；到点提醒：铃声 + 振动 + 通知（倒计时归零后悬浮窗高亮闪烁）
- 倒计时进行中退出 App / 锁屏：到点仍必须提醒（Android 走前台服务+闹钟兜底；鸿蒙走代理提醒 reminderAgent，见技术方案）

**F4 权限与保活引导（转化关键页）**
- 首启流程：3 步引导（悬浮窗权限 → 通知权限 → 电池/后台设置），分厂商定制文案与跳转路径（Android：小米/OPPO/vivo/荣耀/三星；鸿蒙：系统权限弹窗+后台运行引导）
- 权限状态可视化：App 首页常驻「悬浮窗已开启/去开启」状态卡

**F5 设置**
- 时间制式、秒/毫秒、默认样式、开机自启（Android）、息屏暂停策略、提醒铃声与振动、关于

### 3.2 P1 —— v1.x 迭代

- **多悬浮窗并存**：时钟 + 倒计时同时悬浮（各窗独立拖放）
- **Android 桌面小组件**：2×2 时钟 / 4×2 倒计时
- **鸿蒙服务卡片**：2×2 数字时钟 / 2×4 翻页钟
- **鸿蒙实况窗**：倒计时进行中在锁屏/状态栏/通知中心显示倒计时胶囊（HarmonyOS 6 支持到 0 自动结束）
- **计时记录**：秒表历史（时长、计次）、倒计时历史；本地导出
- **防误触锁定**：锁定后悬浮窗不响应拖动，只显示
- **快捷时长磁贴**：通知栏快速启动 3/5/10 分钟倒计时

### 3.3 P2 —— 观望

番茄钟（25/5 循环）、倒数日、NTP 对时校准（抢购场景）、主题商店与付费样式、平板适配、时钟翻页动画

### 3.4 明确不做（v1）

系统监控（网速/CPU/内存）、云同步与账号、手表端、广告（任何形式的广告都不做，作为产品原则）

## 4. 页面结构与信息架构

```
App
├── 首页（计时）
│   ├── 顶部：当前大时钟 + 日期
│   ├── 模式卡：秒表 / 倒计时 / 时钟（卡片内直接启动）
│   ├── 进行中：当前计时状态卡（暂停/继续/关闭悬浮窗）
│   └── 底部 Tab：计时 ｜ 样式 ｜ 记录(P1) ｜ 我的
├── 样式页：6 种预设样式卡 + 自定义（大小/透明度/颜色/背景/显示元素）
├── 我的：权限状态卡、设置项、关于
└── 系统层
    ├── 悬浮窗（时钟/秒表/倒计时，可多实例(P1)）
    ├── 前台常驻通知（Android）/ 通知（鸿蒙）：暂停、+1min、关闭
    └── 鸿蒙：服务卡片 + 实况窗(P1)
```

## 5. 关键交互定义

| 交互 | 行为 |
| --- | --- |
| 悬浮窗单击 | 展开迷你控制条（暂停/继续、重置、隐藏、设置） |
| 悬浮窗双击 | 最小化为小圆点（再次双击恢复） |
| 拖动 | 全屏任意拖动；松手后若贴近边缘 → 吸附（留 40% 露出） |
| 倒计时归零 | 悬浮窗变主题警示色闪烁 10s + 铃声/振动 + 通知；点击停止 |
| 电源键息屏 | 悬浮窗自然消失（系统行为）；亮屏恢复；计时照常（时间戳机制，见技术方案） |
| 倒计时进行中杀进程 | 重新打开 App 提示「倒计时仍在继续」（Android/鸿蒙系统级兜底保证到点提醒） |

## 6. 权限清单（最小化）

| 权限 | Android | 鸿蒙 | 用途 | 必须 |
| --- | --- | --- | --- | --- |
| 悬浮窗 | `SYSTEM_ALERT_WINDOW`（特殊权限，设置页开启） | `ohos.permission.FLOAT_WINDOW`（user_grant 弹窗） | 核心功能 | ✅ |
| 通知 | `POST_NOTIFICATIONS`（13+ 运行时） | 通知授权 | 前台服务常驻通知/到点提醒 | ✅ |
| 前台服务 | `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE`（API 34+） | —（鸿蒙无同类申报，悬浮窗+长时任务见技术方案） | 计时保活 | ✅ |
| 精确闹钟 | `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | —（用 `reminderAgentManager` 代理提醒） | 倒计时到点兜底 | ✅ |
| 振动 | `VIBRATE` | 系统能力 | 到点提醒 | ✅ |
| 开机自启 | `RECEIVE_BOOT_COMPLETED` | — | 可选，默认关 | ⭕ |
| 网络 | 无 | 无 | v1 不需要任何网络权限 | — |

**隐私红线**：不申请定位、通讯录、存储、电话权限；无网络权限（v1 离线可用）；不收集任何用户数据。

## 7. 非功能需求

| 项 | 指标 |
| --- | --- |
| 计时精度 | 秒级模式与系统时间误差 ≤ 1s（时间戳驱动）；毫秒模式 UI 刷新 ≥ 30fps，累计误差 ≤ 50ms/10min |
| 功耗 | 悬浮秒级刷新前台服务功耗 ≤ 1.5%/小时（目标值，实测校准）；息屏 0 额外功耗 |
| 冷启动 | App 首页 < 1.5s；悬浮窗复现（从通知/重开）< 800ms |
| 崩溃率 | Crash 率 < 0.1% |
| 兼容 | Android 8.0+（API 26+）；HarmonyOS NEXT 5.0+（API 12+） |
| 语言 | 简体中文首发；文案外置便于国际化 |

## 9. 验收标准（MVP 出口）

1. 小米/OPPO/vivo/荣耀/三星 各 1 台真机 + 鸿蒙真机（Mate 60/70 或 Pura 系列）：悬浮窗在微信、抖音、浏览器、游戏场景下正常显示、拖动、走秒
2. 倒计时锁屏 30 分钟后到点：铃声+振动+通知 100% 触达
3. 息屏 1 小时再亮屏：时间显示立即正确（无累计误差）
4. 权限引导：全新安装用户 3 步内完成悬浮窗开启（每步有兜底路径）
5. 鸿蒙后台保活 Spike 结论落地：明确「应用退后台后悬浮窗持续刷新时长」并写入产品承诺（如需限制，引导页明示）
